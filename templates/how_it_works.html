How it works

Protection you can inspect.

CogniShield produces a protected local copy, measures image quality, tests JPEG compression, and signs the exact output bytes for later verification.

01 — Input

Your image and controls

CogniShield converts the selected image to RGB for a consistent processing path. The original image stays beside the protected result so you can inspect what changed.

  • Perturbation budget: largest permitted change per pixel (1–16 out of 255).
  • Seed: gives the same noise pattern when settings are unchanged.
  • Compression feedback: repeats a JPEG-aware adjustment to better survive recompression.
02 — Protection

How the protected copy is made

The protection module generates a high-frequency noise field from your seed. It weights naturally detailed areas, then limits every pixel change to your selected budget. This keeps the edit much less visible than an unrestricted modification.

Seeded noise→Edge mask→Bounded perturbation→Protected PNG
03 — Quality

What the quality table means

After protection, the app compares the original and protected images. These values describe visual similarity; they do not claim that an image is authentic or safe in every context.

PSNR
Higher generally means less visible pixel difference.
SSIM
Closer to 1.0 means more similar image structure.
MSE
Average squared pixel error; lower is better.
Mean / max delta
Average and largest absolute pixel changes.
04 — JPEG tests

Compression robustness

Images are often recompressed when shared. For each selected JPEG quality, CogniShield saves a compressed protected image and compares it with the original.

The JPEG table shows metrics at 95, 85, 75, 60, or 50 quality, while the preview cards let users inspect the effect visually.

05 — Provenance

Signing and verification

CogniShield creates a SHA-256 hash of the protected PNG, then signs it with a local Ed25519 key. The downloadable JSON manifest holds the hash, signature, settings, signing time, and public-key filename.

Protected PNG→SHA-256 hash→Ed25519 signature→Manifest JSON

This proves the file matches the signed bytes. It does not prove a scene is objectively real or identify who created it.

06 — Optional model test

SD-Turbo comparison

If you enable Run SD-Turbo target test and have the local model installed, CogniShield sends both original and protected images through the same prompt, seed, and settings.

The output pair lets you inspect the difference. This optional test never changes the protected image or its signed provenance record.

Local by design

Your processing path

The app runs locally at 127.0.0.1. Protection outputs, optional model results, and cryptographic keys remain in the project folders on your computer. This interface does not send the image to an external upload service.
