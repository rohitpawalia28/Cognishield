CogniShield makes a protected copy of your image, measures how much it changed, tests it against JPEG compression, and signs the exact output bytes so the file can be verified later.

Your image and controls

CogniShield converts the selected image to RGB so every image takes the same processing path. The original stays beside the protected result so you can see exactly what changed.

  • Perturbation budget: the largest change allowed for any pixel, from 1 to 16 out of 255. The Subtle, Balanced and Strong presets set this for you.
  • Seed: gives the same noise pattern when the other settings don't change.
  • Compression feedback: repeats a JPEG-aware adjustment so the protection holds up better after recompression.

How the protected copy is made

The protection module generates a high-frequency noise field from your seed. It puts more of the change into naturally detailed areas, then limits every pixel to your budget. That keeps the edit far less visible than an unrestricted change.

What the quality numbers mean

After protection, the app compares the original with the protected image. These values describe visual similarity. They don't claim that an image is authentic or safe in every context.

PSNR
Higher generally means less visible pixel difference.
SSIM
Closer to 1.0 means more similar image structure.
MSE
Average squared pixel error. Lower is better.
Mean / max change
Average and largest absolute pixel changes.

Compression robustness

Images are often recompressed when they're shared. For each JPEG quality you select, CogniShield saves a compressed copy of the protected image and compares it with the original.

The JPEG tests tab shows the numbers for qualities 95, 85, 75, 60 or 50, and the inspection images let you check the effect by eye.

Signing and verification

CogniShield computes a SHA-256 hash of the protected PNG and signs it with a local Ed25519 key. The provenance record you download holds the hash, signature, settings, signing time and public-key filename.

  2. SHA-256 hash
  3. Ed25519 signature
  4. Provenance JSON

This proves the file matches the signed bytes. It doesn't prove a scene is real or identify who created it.

Optional SD-Turbo test

If you turn on Run the SD-Turbo model test and the model is installed locally, CogniShield sends the original and protected images through the same prompt, seed and settings.

You can compare the two outputs side by side. This test never changes the protected image or its signed provenance record.

Everything stays on your computer

The app runs locally at 127.0.0.1. Protected images, model results and your signing keys stay in the project folders on this computer. Nothing is uploaded to an outside service.
